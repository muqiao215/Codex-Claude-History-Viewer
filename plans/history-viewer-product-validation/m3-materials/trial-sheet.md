# History Viewer：首次试用任务单

对象：未参与本项目开发的试用者。建议预留 20–30 分钟；这不是限时考试，卡住本身就是反馈。全部记录使用合成数据，不需要你的个人日志或 API key。

## 准备与启动

本轮仅验收 Linux + Python 3.8+ + 现代浏览器。使用 v1.1.0-rc.1 Release 的源码包；它包含候选源码和合成数据。运行 `python3 app.py --version` 核对版本，合成数据哈希见本目录 manifest.json。使用没有个人 Agent 历史的干净 Linux 账户；应用会自动发现其他来源，不应在个人日常账户直接演示。

解压本包后，在含 app.py 的目录打开终端：

```bash
python3 app.py --codex-dir ./demo/codex --claude-dir ./demo/claude --openclaw-dir ./demo/empty-openclaw --data-dir ./demo/.m3-data --host 127.0.0.1 --port 8787
```

打开浏览器访问 http://127.0.0.1:8787 。没有 Python、命令失败、页面打不开或显示陌生数据时，请记下现象，不要自行补装未知依赖。用仓库 README 排查可以计为自主完成；得到他人提示则记录提示内容。

## 请独立完成

1. 启动并找到一条讨论“给会话侧栏增加按最后活动排序”的 Codex 会话。写下会话标题或 ID，以及你如何找到它。
2. 找到另一条讨论本地日志查看器的 Codex 会话。判断其中有没有工具执行失败；写出一条能支持判断的证据，以及在哪里看到它。不要仅凭助手说“完成”判断成功。
3. 为第二条会话打开交接预览，选择一个主题，导出 `.md` 和 `.html`；打开文件，确认内容对应你刚才选中的会话。写下下一位接手者应注意什么。
4. 可选：切到 Claude 查看一条会话，再切回来；观察是否有旧内容残留。

不要求使用 AI Narrative。本批 demo 没有 token 用量，也没有真实项目计划文件；相关空态是预期行为。
